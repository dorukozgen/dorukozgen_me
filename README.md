# dorukozgen_me

Personal portfolio, CV, and research repository for [Doruk Özgen](https://dorukozgen.me).

Designed with a warm, minimalist editorial aesthetic inspired by Sergey Bunas — featuring Next.js App Router, Tailwind CSS, TypeScript, and deployed on Cloudflare Workers edge via [vinext](https://github.com/cloudflare/vinext).

## Tech Stack

- **Framework**: Next.js App Router (via vinext)
- **Styling**: Tailwind CSS
- **Typography**: Instrument Serif, Inter, JetBrains Mono
- **Edge Deployment**: Cloudflare Workers
- **Package Manager**: Bun

## Development

```bash
# Install dependencies
bun install

# Start local development server
bun run dev

# Build for Cloudflare Workers
bun run build

# Deploy to Cloudflare Workers
bun run deploy
```
